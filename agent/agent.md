# 大模型智能体
**一、Agent 的本质**
Agent = 大语言模型（LLM）+推理能力+工具使用能力
**二、核心原理框架**
graph LR
A[用户目标] --> B[感知模块]
B --> C{规划与决策模块}
C --> D[工具调用]
D --> E[执行反馈]
E --> F{结果评估}
F --> |未完成| C
F --> |完成| G[输出结果]

关键组件说明:
感知模块：理解用户意图与环境上下文； 技术：Prompt工程+上下文学习（ICL）
规划与决策模块：拆解任务、制定步骤、选择工具； 技术：Chain-of-Thought(思维链)+ReAct框架（Reasoning+Acting）
工具调用：扩展LLM能力边界，如API、数据库、文件系统等； 技术：函数描述（OpenAPI格式）+注册机制
执行引擎：获取工具执行结果； 技术：代码解析器（Python）+API调用代理
反思机制：验证结果有效性，错误时重新规划； 技术：Self-Critique+递归迭代

**优化挑战**
1.工具选择错误
2.无限循环
3.幻觉调用
4.长程依赖
